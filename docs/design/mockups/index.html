Arena League · UI mockups

Static, framework-agnostic screens built only from the shared design system in src/ui/styles/. All names, clubs and numbers are invented EXAMPLE data. Spec: docs/design/_drafts/04-presentation.md.

Try it like the game
Number keys 1–7 switch screens, Space is Continue, ? lists shortcuts, hover any number for its tooltip, Shift pins it, click table headers to sort. Add ?theme=light or ?scale=1.25 to a URL to review themes and interface scale.
Home1

The matchweek hub: next fixture with both lineups, a six-item digest, club money, availability and the table around the cut. One primary action: Continue.
Squad2

Lineup board by starting row with captain and per-fighter presets, inline validation, and a sortable roster with the cap meter and contract status.
Fighter profile

Physical and mental attributes, the race age curve with "you are here", trait badges with rich tooltips, contract, injuries, development and career.
Match report

Scoreboard with rounds, MVP, a "what decided it" rule trace, box score, key-moments timeline, injuries and XP.
League4

17-club standings with promotion, tournament and relegation zones, plus the 8-club bracket: projected today, or last season's result.
Market5

Free agents with role filters, wage headroom, willingness, a compare tray and the offer dialog with its budget impact.
Component sheet

Tokens, type, role glyphs, traits, ratings, tables, feedback and overlays in one page, with a color-vision simulator for review.
